# AJ Trade Value pra Ste <3

Calculadora de trocas do **Animal Jam Classic**. Você coloca até 4 itens de cada lado, igual à janela de troca do jogo, e a balança diz se **vale muito**, **vale**, é **justo**, **não vale** ou **não aceite**.

**[Abrir o site](https://aj-trade.vercel.app)** · **[Baixar o app para Windows](https://github.com/yurirubim1/AJ-trade/releases/latest)**

## Como usar

Abra o site [aj-trade.vercel.app](https://aj-trade.vercel.app) no celular ou no computador. Não precisa instalar nada.

- Toque num espaço vazio e busque o item em português ou inglês: `preta longa`, `pl`, `cocar azul`, `asas`, `pet foca`, `beta`, `headdress`…
- Sem digitar nada, o catálogo mostra os itens mais negociados e depois **todos os itens com foto de cada cor**, em ordem de valor ou A–Z.
- Os filtros separam Spikes, Pets (incluindo códigos de pet), Betas, RIMs, Cabeça, Pescoço, Costas, Pernas, Cauda e Toca.
- Cada item escolhido tem um link "ver no wiki" para conferir a página original.
- A troca fica salva no link. Dá para mandar o link para um amigo ver a mesma troca.

## Aplicativo para Windows

O app é a mesma balança, numa janela própria, e **atualiza os valores sozinho uma vez por dia**.

1. Baixe na [última versão](https://github.com/yurirubim1/AJ-trade/releases/latest):
    - [`AJ-Trade-Value-instalador.exe`](https://github.com/yurirubim1/AJ-trade/releases/latest/download/AJ-Trade-Value-instalador.exe) instala e cria um atalho.
    - [`AJ-Trade-Value.exe`](https://github.com/yurirubim1/AJ-trade/releases/latest/download/AJ-Trade-Value.exe) abre direto, sem instalar.
2. Na primeira vez, o Windows pode mostrar o aviso "O Windows protegeu o computador", porque o programa não é assinado digitalmente. Clique em **Mais informações → Executar assim mesmo**.

A barra no topo mostra quando os valores foram baixados e tem o botão **Atualizar agora** (ou a tecla F5). Sem internet, o app continua funcionando com os valores que já tem.

Para ganhar as novidades do app, baixe de novo pela [última versão](https://github.com/yurirubim1/AJ-trade/releases/latest).

## De onde vêm os valores

Todos os valores vêm do [AJ Item Worth Wiki](https://aj-item-worth.fandom.com), o wiki mais completo e atualizado de valores do AJ Classic (cerca de 1.280 páginas), com cada item e cada cor.

O wiki usa várias "moedas". A balança converte tudo para diamantes, com a escala do próprio wiki, e mostra o resultado em **Pretas Longas (PL)**:

| Unidade do wiki | Diamantes |
|---|---|
| RIM obtenível | ~0,35 |
| Beta de roupa | 1 |
| Beta de toca | 3 |
| Pulseira longa ruim / média / boa / preta | 19 / 27,5 / 32,5 / 47,5 |
| Coleira curta ruim / média / boa / preta | 62,5 / 77 / 110 / 170 |
| Coleira longa ruim / média / boa / vermelha | 160 / 200 / 247,5 / 320 |
| **Coleira longa preta (PL)** ou 1 "Variety" | **475** |

Quando o wiki mostra duas colunas (por exemplo "2 Good Long Collars" e "450-500 Diamonds"), vale a de diamantes, que é a mais precisa.

### O que o resultado quer dizer

A balança compara o que você recebe com o que você dá:

| Você recebe | Resultado |
|---|---|
| 40% a mais ou mais | VALE MUITO (W grande) |
| 10% a 40% a mais | VALE (W) |
| até 10% de diferença | JUSTO |
| 10% a 30% a menos | NÃO VALE (L) |
| 30% a menos ou pior | NÃO ACEITE (L grande) |

A balança também avisa sobre itens "difíceis de avaliar" (que ficam fora da conta), valores mínimos (pets), itens à venda na loja, "talvez mais/menos" e upgrade/downgrade.

Valores mudam. Para trocas grandes, confira a página do item no wiki.

## Aba Automação (só no app)

O app tem uma segunda aba para automatizar tarefas repetitivas no computador, como preencher formulário ou repetir cliques num programa. É um utilitário à parte, sem relação com o Animal Jam.

**Não use a automação para jogar Animal Jam sozinho.** O jogo proíbe programas que jogam por você, e a conta pode ser banida.

Passos disponíveis: **clique**, **arrastar**, **mover mouse**, **escrever texto**, **tecla** (com Ctrl, Shift, Alt, Win), **esperar** e **rolagem**. Cada passo tem sua própria espera, e a automação pode repetir quantas vezes você quiser.

- **Gravar** (botão ou tecla **Delete**) anota os cliques, arrastos e teclas que você fizer e monta os passos sozinho. A mesma tecla encerra, e dá para trocar qual tecla é no seletor ao lado.
- **📍 Marcar posição** conta 3 segundos e guarda onde o mouse estiver.
- **F8**, em qualquer lugar da tela, marca a posição na hora no passo escolhido.
- **▶** em cada passo executa só aquele passo, para conferir antes de rodar tudo.
- **F9** para tudo na hora, mesmo com outro programa na frente.
- A espera antes de começar (3 segundos) serve para você trocar de janela.
- As automações ficam salvas por nome.

Também dá para fazer passos que olham a tela: **Esperar imagem**, **Clicar na imagem**, **Se aparecer imagem…**, **Ir para passo** e **Aviso**. As imagens são recortadas da sua própria tela com **📷 Recortar da tela**, e **📐 Marcar área** limita onde procurar.

Os cliques e teclas vão para a **janela que estiver na frente**, então confira qual é antes de rodar.
